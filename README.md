# Hotel Registration System (Flask CRUD)

A simple CRUD (Create, Read, Update, Delete) web application for managing
hotel registrations, built with Flask and SQLite.

## Features
- Add new hotel records
- View all registered hotels in a table
- Edit/update hotel details inline
- Delete hotel records
- Flash messages for success/error feedback
- Automatically creates the `hotel` table even if `example.db` already
  exists (existing tables/data are left untouched)
